# Playkit mods

The community mod list for [Playkit](https://github.com/MCbabel/playkit), the mod launcher for Project Playtime.

Every folder in [`mods/`](mods) is one mod. Playkit reads [`index.json`](index.json), which is built automatically from this repository.

Mods are stored as binary patches against the original game files, so this repository never contains files from the game itself.

**Want to add a mod?** Read [CONTRIBUTING.md](CONTRIBUTING.md).
